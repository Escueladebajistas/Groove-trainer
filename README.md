# 🎸 Groove Trainer V2

Drum Machine para la Escuela de Bajistas de Engativá.

## Funciones

- Metrónomo/drum machine 4/4.
- BPM de 40 a 240.
- Presets de tempo.
- Kick, Snare y Hi-Hat.
- Secuenciador de 16 pasos.
- Edición de cada golpe haciendo clic en la cuadrícula.
- Patrones Funk, Rock, R&B y Latin.
- Swing de 50% a 70%.
- Indicador visual del paso actual.
- Sonidos generados con Web Audio API.
- Diseño responsive para celular y computador.
- No necesita archivos de audio externos.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube estos cuatro archivos a la rama `main`.
3. Entra a `Settings`.
4. Entra a `Pages`.
5. En `Build and deployment`, selecciona `Deploy from a branch`.
6. Selecciona `main` y la carpeta `/ (root)`.
7. Pulsa `Save`.
8. GitHub generará la URL de tu aplicación.

## Cómo usar la Drum Machine

1. Selecciona Funk, Rock, R&B o Latin.
2. Pulsa PLAY.
3. Cambia el BPM con + y -.
4. Haz clic en cualquier casilla del secuenciador para activar/desactivar un golpe.
5. Usa el control SWING para modificar la sensación rítmica.
